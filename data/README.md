# Data

This project analyzes vehicle-insurance customer and policy information.

## Dataset Scope

The original analysis works with two types of information:

- customer details
- customer insurance-policy details

These datasets are combined during the analysis to support exploratory investigation of customer and premium-related patterns.

## Public Repository

The underlying customer-level source datasets are not included in this public portfolio repository.

This repository focuses on the analysis workflow and Jupyter Notebook rather than redistributing the original customer data.

## Data Source

The exact original dataset source, URL, license, and redistribution terms are **Not confirmed from the uploaded files.**

## Reproducibility

Because the original source datasets are not included, the notebook may require the corresponding input files before all cells can be executed from beginning to end.
