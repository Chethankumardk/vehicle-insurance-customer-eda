# Vehicle Insurance Customer EDA Notebook

This folder contains the Jupyter Notebook used for the vehicle insurance customer exploratory data analysis.

## Main Notebook

`vehicle_insurance_customer_eda.ipynb`

## Analysis Purpose

The notebook works with customer and insurance-policy information to create a consolidated dataset for exploratory analysis.

The business scenario focuses on understanding customer and premium-related information that may support decisions concerning premium discounts.

## Technical Focus

The project demonstrates:

- Python data analysis
- Pandas DataFrame operations
- NumPy
- data inspection and preparation
- data cleaning
- combining information from multiple datasets
- exploratory data analysis
- customer and policy data analysis

## Scope

This notebook represents descriptive and exploratory analysis.

It should not be interpreted as a validated insurance pricing, risk-assessment, or predictive machine-learning model.
